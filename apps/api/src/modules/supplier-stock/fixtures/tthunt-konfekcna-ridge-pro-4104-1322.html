Inovovaný set Swedteam Ridge Pro je vhodný pre väčšinu loveckých aktivít, obzvlášť pre aktívny lov. Set je vyrobený z odolného materiálu s vode a vetruodolnou membránou COVERTEX®100, ktorá vyniká výbornými priedušnými vlastnosťami. Množstvo praktických vreciek na bunde je prispôsobených pre strelcov ľavákov aj pravákov.

Materiál:

  • vonkajší: 100% polyester
  • membrána 100% polyuretan
  • podšívka 100% polyester®

Technologie

YKK® Tento odev je vybaveny YKK® zipsom.
Desolve® Veil Unikátny kamuflážny vzor, ktorý bol vyvinuty na základe najmodernejších poznatkov o videní zvierat. Vysoký kontrast a použité farvy ku okolnému prostrediu robia ľudskú siluetu pre zver obtiažne rozoznatelnu. DESOLVE® Veil je zvlášt vhodný do lesa.
